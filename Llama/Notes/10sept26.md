## Llama 3.1-8B P3 RELAUNCH from step 0

The run that halted on the 6th reached its permutation baseline and never took a gradient step. It relaunches from step 0 with four corrections, three of them shared with Mistral and one specific to this model.

### dtype 

Adafactor's failed allocation was 2.63 GiB, which is exactly 172,451 x 4096 x 4. Every memory comment in this script assumes a bf16 embedding at 1.32 GiB. The matrix was fp32 at runtime, so the weight, its gradient and the optimiser's full-shape 
update temporary were each twice the width the configuration was budgeted for.

The embedding is now cast to bf16 after the resize and before tying, and a guard raises immediately afterwards if it is not. Roughly 4.2GB is recovered against a shortfall of 2.63 GiB, so if the diagnosis holds the run fits with room. If the 
guard reports the matrix was already bf16, the diagnosis is wrong, the budget is genuinely exhausted, and the remaining move is WakeOverlay: 44,195 trainable Wake rows rather than the whole 172,451, which also removes the gradient mask instead 
of computing around it.

The optimiser stays Adafactor. Paged 8-bit AdamW was tried on the 9th and relocated the pressure into host memory, terminating the runtime without a traceback.

### resume-path 

Trainer-native resume restores the adapter, the optimiser moments, the scheduler and `trainer_state.json`, but not the embedding matrix: PEFT writes the resized embedding into the adapter file and ignores it on load. Caught on Mistral, where a 
resume at step 100 read L_morpheme 0.6698, the pre-training baseline, against the 0.6546 the checkpoint had reached.

DTYPE THEORY DISPROVEN 2026-09-11 by a 4-step smoke test. The embedding is bf16 (1.32 GiB) and adafactor STILL allocated 2.63 GiB, the fp32 width. The reason is in adafactor's own step(). It upcasts the gradient itself, so the temporary is full-shape fp32 regardless of the parameter dtype. The bf16 cast is kept but it cannot address this.

```
import torch
from collections import Counter
w = model.get_input_embeddings().weight
o = model.get_output_embeddings()
print(f"embedding : {w.dtype} {tuple(w.shape)} {w.numel()*w.element_size()/2**30:.2f} GiB")
print(f"emb grad  : {'none' if w.grad is None else str(w.grad.dtype)+' '+format(w.grad.numel()*w.grad.element_size()/2**30,'.2f')+' GiB'}")
print(f"lm_head tied: {o is not None and o.weight.data_ptr() == w.data_ptr()}")
par = sum(p.numel()*p.element_size() for p in model.parameters() if p.is_cuda)/2**30
grd = sum(p.grad.numel()*p.grad.element_size() for p in model.parameters() if p.grad is not None and p.grad.is_cuda)/2**30
print(f"params {par:.2f} | grads {grd:.2f} GiB")
print(f"allocated {torch.cuda.memory_allocated()/2**30:.2f} | reserved {torch.cuda.memory_reserved()/2**30:.2f} GiB")
print(Counter(str(p.device) for p in model.parameters()))
```
